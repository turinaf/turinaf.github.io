# turinaf.github.io

Personal website of Turi Abu — PhD student in Computer Science at Tsinghua University.

Built with [Next.js](https://nextjs.org) and [Tailwind CSS](https://tailwindcss.com).

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site. Site content lives in `src/data/`.
